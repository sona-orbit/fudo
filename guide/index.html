App 操作說明

照 App 現在的樣子，一段一段配畫面看。也可以從目錄跳到想看的地方。

每天有三分鐘，你哪裡都不去？

不動修行是陪你每天練這件事的 App：坐下來的幾分鐘，走路、洗碗、通勤的時候，都在練知道自己在。

第一次打開

  1. 先看六頁「為什麼這樣練」，右上可以略過。
  2. 按住火苗，亮起來就開始，先練 5 秒；接著再練一分鐘，也可以之後再說。
  3. 選以後每次坐多久，再決定時間到要不要通知你。
  4. 回到首頁，跟著小引導把四個方向各滑一次。

長按火苗，開始

首頁：一座塔，四個方向

中間是你自己的塔。從畫面中間往四個方向滑，就到四個地方。

  1. 點火苗或石頭，它們會有反應；按住火苗就開始靜坐。
  2. 點一下空白處，左上出現「搭配」、右上出現「設定」，幾秒後收起。
  3. 最下面一行是累計不動多少分鐘。每累積 300 分鐘，多一顆可以疊上塔的石頭。

靜：坐著，知道自己在

  1. 按住火苗，光暈變大、亮起來就開始。
  2. 畫面轉暗。發現自己跑掉了，點螢幕任何地方一下，記一次。
  3. 時間到手機輕震兩下；沒停的話會繼續算。想停就再按住火苗。
  4. 結果寫成「5 分 · 跑掉 3 次」，想寫就留一行，按「收進塔裡」。

動：在生活裡

  1. 首頁往右滑，選一件正在做的事和多久，按「開始」。
  2. 做的時候留意自己在不在，跑掉了就點「跑掉」。
  3. 可以關掉 App：鎖定畫面和動態島看得到時間，也能在那裡記跑掉、結束。
  4. 回來按「收下」，這段就算進今天；不想留就按「這次不算」。

夜裡收尾

  1. 日落後，當天有練過，首頁轉成夜色，下面出現「收尾」。
  2. 回答一題：今天，有想起自己的時候嗎？兩個答案一樣大，沒有對錯。
  3. 想寫就留一行，大家闔眼，今天收好。

校準 · 每週回顧

  1. 首頁往左滑就是「校準」。回顧的日子在「設定」裡選。
  2. 那天依序：看這一週、選什麼把你帶走、寫一段給自己、放進一件事。
  3. 下一週先問同一件事怎麼樣了。寫過的都收在紀錄「路上」裡的「議題」。

設定

  1. 點首頁空白處，再點右上的齒輪。
  2. 練習：一次坐多久、開始前倒數、開始時輕震、坐著時顯示時間。

鎖定畫面與動態島

靜和動的計時會出現在鎖定畫面和動態島，在那裡也能結束。

  1. 看不到的話，打開 iPhone 的「設定」，找到這個 App，打開「即時動態」。
  2. 再到「設定」裡的「Face ID 與密碼」，確認鎖定時可使用的項目裡「即時動態」是打開的。
  3. 動態島只有有動態島的 iPhone 才有；其他 iPhone 在鎖定畫面看。
