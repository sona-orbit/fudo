アプリの使い方

いまのアプリのとおりに、一つずつ画面つきで説明します。目次から飛んでもかまいません。

一日三分、どこへも行かない時間を。

不動修行は、これを毎日続けるためのアプリです。座る数分間も、歩く・皿を洗う・通勤する時間も、自分がここにいると知る練習になります。

はじめて開いたとき

  1. 最初に「なぜこう練習するのか」が六ページ。右上で飛ばせます。
  2. 炎を押さえて、明るくなったら始まり。まず 5 秒、つづけて一分。あとにしてもかまいません。
  3. ふだん何分座るかを選び、時間になったら知らせるかを決めます。
  4. ホームに戻ると小さな案内があり、四つの方向を一度ずつスワイプします。

炎を長押しして、始める

ホーム：塔がひとつ、方向が四つ

まん中にあるのは自分の塔。画面の中ほどから四方向にスワイプすると、四つの場所へ行けます。

  1. 炎や石をタップすると反応します。炎を押さえると座り始めます。
  2. 何もないところをタップすると、左上に「着せかえ」、右上に「設定」が出て、数秒で消えます。
  3. いちばん下の一行は、これまでの静かな時間の合計。300 分ごとに、塔に積める石がひとつ増えます。

静：座って、ここにいると知る

  1. 炎を押さえます。光がひろがり、明るくなったら始まり。
  2. 画面が暗くなります。それたと気づいたら、どこでも一回タップして記録します。
  3. 時間になると二回ふるえます。止めなければそのまま数えます。止めたいときはもう一度炎を押さえます。
  4. 結果は「5 分 · それた 3 回」のように出ます。一言残したければ書いて、「塔にしまう」を押します。

それるのは失敗ではありません。気づいたことが練習です。

それた

あと 3 分

気がそれたと気づいたら、タップして一回記録。

塔にしまう

動：暮らしのなかで

  1. ホームから右へスワイプ。いましていることと時間を選び、「開始」。
  2. しているあいだ、自分がここにいるかに気をつけ、それたら「それた」をタップ。
  3. アプリを閉じてもだいじょうぶ。ロック画面とダイナミックアイランドに時間が出て、そこでそれた記録も終了もできます。
  4. 戻ったら「残す」で今日にかぞえます。残したくなければ「今回は数えない」。

夜のしめくくり

  1. 日が沈んだあと、その日に練習していればホームが夜の色になり、下にしめくくりが出ます。
  2. 問いはひとつ：今日、自分を思い出したときはあった？ 二つの答えは同じ大きさで、どちらも正解です。
  3. 書きたければ一行。みんな目を閉じて、今日はおしまい。

あったなかった

ふりかえり · 週のふりかえり

  1. ホームから左へスワイプすると「ふりかえり」。ふりかえりの曜日は「設定」で選びます。
  2. その日は順に：今週を見る、気を持っていかれたものを選ぶ、自分に一言書く、ひとつのことにしまう。
  3. 次の週は、まず同じことがどうだったかを聞きます。書いたものは記録の「道のり」の「議題」に残ります。

  3. 下は四ページ：塔、到達、道のり、収集棚。

設定

  1. ホームの何もないところをタップして、右上の歯車へ。
  2. 練習：一回に座る時間、始める前のカウントダウン、始まりの振動、座っているあいだの時刻表示。
  3. ほかに、リマインダーと音、ホームのレベル表示、ふりかえりの曜日、使い方をもう一度。

ロック画面とダイナミックアイランド

静と動のタイマーはロック画面とダイナミックアイランドに出て、そこで終えることもできます。

  1. 表示されないときは、iPhone の「設定」でこのアプリを開き、「ライブアクティビティ」をオンにします。
  2. さらに「設定」の「Face ID とパスコード」で、ロック中にアクセスを許可する項目の「ライブアクティビティ」がオンになっているか確かめます。
  3. ダイナミックアイランドは、それがある iPhone だけです。ほかの機種ではロック画面に出ます。

データとそのほか

データ
アカウントはいりません。記録、残したひとこと、着せかえはこの iPhone の中だけにあり、アップロードされません。アプリを削除すると一緒に消えます。
意見フォーム
週のふりかえりのページを下までスクロールし、このアプリについて、から「意見フォーム」を開きます。何が起きたかを書いて送信します。
医療サービスではありません
不動 Fudo は日々の落ち着く練習で、医療や心のケアのサービスではありません。助けが必要なときは、医師や専門家に相談してください。
